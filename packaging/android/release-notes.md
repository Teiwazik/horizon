**Starling 0.1.5: play offline, and mods for each new world.**

## Install

- **On 0.1.0.1 or later:** Starling offers this update on its title screen: tap **Update**, and Android installs it over (it asks you to allow installs from Starling the first time).
- **New here:** download **`starling-0.1.5-arm64-v8a.apk`** below and open it. Sign in with the Microsoft account that owns Minecraft: Java Edition, or play offline: the game is downloaded from Mojang's servers and prepared on the phone, once. You need a 64-bit phone with Android 8 or newer and Vulkan, and about 2 GB free.

> Installed a test build from GitHub Actions? Uninstall it first: test builds are signed with another key. Worlds kept in the `Starling` folder stay where they are.

## What's new

- **Play offline:** the first start offers **Play offline** beside **Sign in with Microsoft**, so the game installs without an account. Online-mode servers still need the sign-in.
- **Mods and data packs for a new world:** **Create New World > More > Mods & Data Packs** lists the content mods that add blocks or items next to your data packs. Pick them and Starling starts again with those mods and creates the world. Opening a mod's file with Starling now points you there.
- **A steadier first download:** the game's files come over a few connections kept open, and a file is tried again when the network drops for a moment.
- **Your data packs** move into the `Starling` folder with your worlds and packs.

## Report a bug

Open an [issue](https://github.com/JuanLuci/starling/issues/new/choose): the form asks for your phone, your Android version and `Starling/logs/latest.log` (with `previous.log` beside it once Starling has been opened again).
